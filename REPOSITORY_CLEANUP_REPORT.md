## 2. Classification Definitions & Criteria

### A. Keep
Files essential for the operation of the backend application, feature engineering, model inference, and frontend user interface:
* **Core REST Services**: `backend/app.py`, `backend/config.py`, blueprints under `backend/routes/`.
* **Inference Libraries**: `backend/ml/src/predictor.py`, `backend/ml/src/csv_analyzer.py`, `backend/ml/src/text_normalizer.py`.
* **Test Suites**: `backend/tests/integration/test_api.py`.
* **Deployment Assets**: `Dockerfile`, `docker-compose.yml`, `.env.example`, `requirements.txt`.
* **Scientific Reports**: Figures and tables in `backend/ml/reports/`.

### B. Archive
Reference files and legacy checkpoints that are no longer part of active production endpoints, but are retained to preserve historical benchmarks and experimental reproducibility:
* **Legacy Estimators**: Archived in `backend/ml/models/archive/` (e.g., `random_forest_model.pkl`, `xgboost_model.pkl`).
* **Legacy Vectorizers**: Archived in `backend/ml/models/archive/` (e.g., `tfidf_vectorizer.pkl`, `tfidf_vectorizer_random_forest.pkl`).

### C. Delete
Temporary check-in artifacts, scratch files, or test outputs that do not represent reproducible project code and should be removed from the working directories:
* **Diagnostic Scratch**: Any files generated during local debug runs (e.g., `test_write.txt` has been manually removed).

### D. Ignore
Directories and configuration files containing local environment details, credentials, build processes, or temporary runtime output logs. These must never be committed to Git:
* **System Files**: `.DS_Store`, `Thumbs.db`.
* **Local Secrets**: `.env`, `.env.production`.
* **Compiled Bytecode**: `__pycache__/`, `*.pyc`.
* **Diagnostic Logs**: `backend/ml/reports/logs/app.log`.
* **IDE Profiles**: `.idea/`, `.vscode/`.
* **System Notebook Checkpoints**: `.ipynb_checkpoints/`.
